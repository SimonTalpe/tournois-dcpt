# Tournois DCPT

Site web (mobile et desktop) pour organiser des tournois entre collègues de la DCPT, avec des fonctionnalités fun.

## Stack prévue
- React + Vite + TypeScript + Tailwind CSS
- Supabase (base de données, authentification, temps réel)
- Cloudflare Pages (hébergement)

## Fonctionnement
- `main` = version stable, déployée en production.
- Chaque fonctionnalité est développée sur une branche dédiée et fusionnée via Pull Request après test.
